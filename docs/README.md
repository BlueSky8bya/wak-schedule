# docs/

VIC(빅토리) 프로젝트에서 물려받은 문서 중 **이 프로젝트에도 그대로 유효한 것만** 남겼다.

- `agent/` — WHITEHAVEN Agent Harness (현재 상태·지도·결정·계획·인수인계)

- `architecture.md` — 구조·데이터 흐름
- `security-boundary.md` — 공개/비공개 경계와 RLS
- `deployment.md` — Vercel + Supabase 배포
- `tags/` — 태그 2계층 모델·커스텀 색 (⚠ 태그 '내용'은 VIC 콘텐츠 기준 — 우왁굳 콘텐츠로 다시 짜야 한다)
- `ux/` — 모션·햅틱·반응형·Apple HCI 벤치마크 (기능 무관한 설계 원칙이라 유효)

⚠ 문서 본문에는 아직 VIC 시절의 예시·기능명(스티커·비공개 레이어·업 도움)이 남아 있을 수 있다.
읽을 때는 "이 프로젝트에 그 기능이 없다"는 걸 전제로 볼 것. 고쳐야 할 서술을 보면 그때 고친다.

(구 `sop.md`는 VIC 서술이 91곳이라 `agent/archive/sop-vic-2026-08.md`로 보관 — 절차는 `agent/`가 대체.)
