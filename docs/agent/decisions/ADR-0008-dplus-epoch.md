# ADR-0008: 달력 기념일 = 생일(매년)뿐, D+ 기준일 = 2008-11-01(임시)

Status: Accepted
Date: 2026-08-26 (사용자 확정)
Decision Owners: User
Related Change IDs: CHG-20260826-004
Supersedes: 이 문서의 Proposed 안(D+ 기준 2024-02-04, 이세돌 데뷔 연례 표기 포함)

## Context

기념일·D+ 기준의 초안(커밋 fcde3c6)은 위키 출처 추정이었다. 사용자가 확정했다.

## Decision

1. **매년 기념일은 생일 하나** — `07-24 🎂 왁굳형 생일` (본명 오영택, 1987-07-24,
   위키백과·나무위키). 이세돌 데뷔 등 다른 연례 표기는 제거.
2. **D+ 기준일 = 2008-11-01** — 방송 인생 전체를 센다. 시작은 "2008년 11월"까지만
   확인돼 **일자는 1일로 임시**. 정확한 날짜 확인 시 `DEBUT_ISO` 한 곳만 수정.
3. 과거 기록(STREAMER_ONCE)은 비워 둔다 — 연혁을 띄우고 싶어지면 그때 추가.

## Consequences

- 오늘(2026-08-26) 기준 D+6508. 매년 11-01은 "방송 N주년"(2026=18주년),
  100일 단위 마일스톤은 자동 파생.
- (−) 11-01이 실제와 다를 수 있음 — D+ 값이 최대 ±29일 오차. 임시임을 코드
  주석에 명시.

## Revisit Conditions

2008년 실제 첫 방송 일자가 확인될 때 → `DEBUT_ISO`만 수정.
