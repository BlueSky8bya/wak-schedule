# ADR-0013: 색 부채 P0 — 의미 토큰 분리·보라 수렴·표면 스냅·죽은 스타일 제거

Status: Accepted
Date: 2026-08-26
Decision Owners: User (승인: "먼저 4개 해봐") + Agent (실행 설계)
Related: ADR-0003(죽은 꾸미기 제거의 근거), docs/ux/wak-pastel-color-system-research.md(원 제안)

## Context

외부 리서치 문서(wak-pastel-color-system-research.md)가 색 리터럴 2,014곳(고유 1,021)의
부채와 "색 문법 충돌"을 진단했다. 문서의 본 제안(하늘색 기반 '왁물원 피크닉' 팔레트)은
현 크림+연두 정체성의 전면 전환이라 **보류**하고, 팔레트 선택과 무관하게 유효한
저위험 4개만 사용자 승인으로 먼저 실행했다.

## Decision

1. **의미 토큰 층 선언** — `--interactive/--today/--heart/--live/--teaser`(+soft/on 짝)를
   globals :root에 계약으로 둔다. 새 코드는 기반색(--violet 등)이 아니라 의미 토큰을 쓴다.
   기존 소비처는 화면 단위로 점진 이관(P1). live·teaser는 즉시 실소비 시작.
2. **보라 수렴** — 상호작용 보라 6종(#5b34f0·#6b5bd6·#7c6cf0·#6a58e8·#8b7cf0·#5b4bd0 등)을
   `--violet #6b5bd6`(정본) / `--violet-strong #5b4bd0`(텍스트) / `--violet-rgb`(알파)로 통일.
   떡밥의 저채도 보라(#5b4aa6)는 **다른 의미**라 합치지 않고 `--teaser`로 분리.
3. **표면 스냅** — 같은 깊이의 근사중복 크림 화이트(채널 합 Δ≤8, 웜/그린 색조)만
   `--surface/--surface-2/--paper`로 스냅(74곳). 노랑 wash·웜그레이·쿨톤 화이트·순백은
   의미가 달라 제외.
4. **죽은 스타일 제거** — 런타임이 클래스를 방출하지 않음을 전수 감사로 확인한
   스티커·포스터 테마·월드컵·업도움·포스터 아바타/캡쳐/단축키도움말·member-role CSS
   약 2,900줄과 죽은 파일 2개(theme-switch.tsx, theme-actions.ts) 삭제.

## 하지 않기로 한 것

- 하늘색 기반 전면 리팔레트(문서의 본 제안) — 정체성 결정이라 사용자 별도 승인 필요.
  하게 되면 문서의 P1(바탕·표면)만 떼어 별도 계획으로.
- 인사이트 색 문법 재설계(문서 6-5) — "VIC과 똑같이" 지시와 충돌. ▲빨강/▼파랑은
  한국 관습이라 유지.
- 태그 색 개편 — 리서치 문서 스스로 제외한 범위.

## Consequences

- (+) 색 리터럴 고유 수 감소, 보라·표면 일관, 의미 토큰 계약 확립. CSS 약 2,900줄 감량.
- (+) 시각 델타는 보라 정렬(네온→부드러운 계열) 외에 사실상 0 — 픽스처 스크린샷 확인.
- (−) 의미 토큰의 소비처 이관은 P1로 남음(선언만으로는 리터럴 부채가 안 줄어듦).

Revisit: 사용자가 '왁물원 피크닉' 방향을 택하면 P1(바탕·표면) 계획으로 재개.

## 후속(2026-08-26, 같은 날): P1 부분 재개 — '구름빛 클린'

사용자가 "다른 편안하고 깔끔한 느낌"을 요청 → 보류했던 P1의 바탕·표면만 실행했다.
중립 토큰(--paper/--surface/--surface-2/--line/--studio-workbench)을 쿨 화이트/클라우드
계열로 전환하고, 포스터·모바일 아젠다의 웜 크림 리터럴(모래 보더·카키 텍스트·웜 그림자)을
쿨 등가로 치환. **상호작용 색은 문서 제안(Sky)과 달리 기존 보라·골드를 유지** —
골드는 오늘·내비 화살표·선택 상태의 온기 포인트로 남긴다(층: 구름빛 바탕 + 하늘빛 달력 +
골드/하트/태그 포인트). 세이지 잔디 배경(522d702)은 이 전환으로 대체됨.
