## 사용자가 정한 축 (확정)

- **콘텐츠(주체)** = `kind='content'` — 색·통계를 가진다. "무엇을 하는 방송인가"
- **형식(서술)** = `kind='modifier'` — 색 없음(점 표시), 통계 제외. "어떻게 하는가"
- 예: "VR챗 이세돌 합방" → 이세돌(콘텐츠) + 합방(형식) + VR챗(서술)
  "후열로 보는 시네티" → 시네티(콘텐츠) + 후열(형식)
  "VR챗 조공" → 조공(콘텐츠) + VR챗(서술)

스키마 지원: `broadcast_tags.kind`(0037) + `parent_id` 2계층(0036) — 새 마이그레이션 불필요.
