# tests/

- `unit/` — Vitest. `npm test`로 돌린다. **192개 전부 통과 상태**(2026-08-26).
- `e2e/`, `visual/` — Playwright. 실행에 dev 서버 + Supabase가 필요해 아직 한 번도 돌린 적이 없다.

## ⚠ e2e / visual 은 아직 손보지 않았다

VIC(빅토리)에서 그대로 가져온 스펙이라 **이 프로젝트에 없는 기능을 검사한다**:
스티커·꾸미기 모드, 비공개 레이어, 업 도움, 매니저/작업자 화면, 방송 판서.
기준 스냅샷(`*-snapshots/`)도 VIC 화면 픽셀이라 전부 지웠다.

Supabase를 붙이고 `npm run dev`가 뜨면 그때 스펙별로 분류할 것:
지금도 유효한 것(달력 렌더·공개 API 경계·반응형)은 고쳐 살리고, 사라진 기능 것은 지운다.
스냅샷은 새 화면으로 다시 뜬다(`--update-snapshots`).
